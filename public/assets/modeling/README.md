# Modeling Portfolio Images

Place your modeling portfolio images in this folder.

## Recommended Image Specifications:
- **Format**: JPG or PNG
- **Aspect Ratio**: 3:4 (portrait) for best display
- **Resolution**: At least 1200px width for high quality
- **File Size**: Optimize images to < 500KB each for faster loading
- **Naming**: Use descriptive names like `image1.jpg`, `image2.jpg`, etc.
